Muse Gadget Web Flasher

Flash the open source Muse Gadget firmware onto your ESP32 board, straight from Chrome or Edge on a desktop computer.

SDK token

Change Forget

A gadget needs your SDK token to pair. Get it from gadgets.muse.ai (Account > SDK tokens). It's sent to the gadget over USB after installing, the gadget keeps it through updates, and this browser remembers it for next time.

Install

You haven't entered your SDK token yet. You can install without it, but the gadget can't pair until it has one.

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) connection.

Keep this tab in front while installing. Updating keeps your pairing, Wi-Fi settings and token. When it's done, close the installer: the page sends your token, and you set the gadget up in the Muse app.
