Muse Gadget Web Flasher

Flash the open source Muse Gadget firmware onto your ESP32 board, straight from Chrome or Edge on a desktop computer.

SDK token

Change Clear

A gadget needs your SDK token to pair. Get it from gadgets.muse.ai (Account > SDK tokens). It's sent to the gadget over USB after installing, and the gadget keeps it through updates.

Off unless you tick it. When it's on, the page saves the token in this browser's local storage once it reaches a gadget, unencrypted, so anyone who uses this browser profile on this computer can read it. Untick it or press Forget saved token to delete it.

2

Install

Take the gadget off your wrist and set it down first: moving it can wake it and stall the update.

You haven't entered your SDK token yet. You can install without it, but the gadget can't pair until it has one.

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) connection.

Keep this tab in front while installing. Updating keeps your pairing, Wi-Fi settings and token. Once the firmware is written, the page checks the version the gadget runs, sends your token and says Done; then you set the gadget up in the Muse app.

Device settings below is connected to a gadget. Disconnect it there to install.
